车系兴趣
Top10		 车系主数据 + 频次计数；自然日（1 天内）口径 AI会话浏览≥2次 ① 会话表达车系兴趣即记录；② 站内点击查看 ≥2 次直录。⚠️ 已裁决：会话条件无频次，整体按时间倒序排序，浏览命中项附频次角标 整体时间倒序；上限 10，超出依次被替换
车身类型
Top3		 枚举：Hatchback / Sedan / SUV / Minivan / Pickup / Van / Deportivo / Coupe / Convertible AI会话车系反推 ① 会话中表达车身类型偏好；② 未表达时由「车系兴趣 Top」对应的车身类型反推，去重取 3 个 按车系兴趣权重排序；上限 3
全款预算段
单值		 精确数值段（如 $250,000–350,000）或表达「xx 左右/区间」时按 ±15% 落段 AI会话 会话中表达新车价格/指导价/预算区间即记录；同时联动记录车系兴趣的最低/最高价作为参照区间 单值，以最后更新时间为准（新表达覆盖旧值）
首付占比区间
单值		 枚举 8 档：[0-10%) / [10-15%) / [15-20%) / [20-25%) / [25-30%) / [30-40%) / [40-50%) / [50%+) AI会话 语义关键词：用于首付、付首付、首付预算、首付要付百分之几等，提取比例 X% 落入对应档位 单值，最新表达覆盖
月供区间
单值		 枚举 4 档：<$5,000 / $5,000–10,000 / >$10,000 / 不限 AI会话收入推导 ① 记录用户最新表达的月供，仅保留一个区间（如先说 5,000–6,000 再说上限提到 10,000 → 更新为 $5,000–10,000）；② 「5000 左右」按 ±15% 落段；③ 表达过月收入且要购车 → 月供区间 = 月收入 15%–30% 对应段 单值，最新表达覆盖
能源类型
Top6		 枚举：燃油 / 柴油 / 插电混动 / 油混 / 纯电 等 AI会话车系反推 ① 会话中表达能源偏好；② 未表达时按车系兴趣由高到低取车系的能源类型。⚠️ 已裁决：一个车系有多个能源类型时全部记录并去重 时间倒序；上限 6，去重保存
语言偏好
单值		 Español / English / 中文 / XX（可扩展） AI会话系统设置 会话维度记录；优先级：上下文中要求记忆的 > 系统设置（如系统默认西语、用户会话内用中文 → 记中文） 单值，会话覆盖系统
