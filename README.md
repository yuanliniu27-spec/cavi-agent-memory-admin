# CAVI · Agent 记忆标签运营后台（原型）

面向内部运营的**记忆标签查询后台**高保真交互原型，数据为模拟数据。

## 在线预览

启用 GitHub Pages 后访问：`https://yuanliniu27-spec.github.io/cavi-agent-memory-admin/`

## 功能

- **用户记忆查询（主功能）**
  - 标识反查：device_id / uuid / 关联账号 / 手机号（脱敏） / 邮箱
  - 环境筛选：语言 / 设备端（移动 · PC） / 登录状态 / 更新时间区间
  - **标签筛选（两级交互）**：先点维度（品牌偏好 / 车系兴趣 / 车身类型 / 全款预算段 / 首付占比区间 / 月供区间 / 能源类型），再在下拉中勾选具体标签值（如品牌 → Nissan / Toyota / Kia / Ford…）
    - 维度内多选 = 或（OR）；维度之间 = 且（AND）
  - 用户列表 11 列：设备标识 / UUID / 设备端 / 语言 / 品牌偏好 Top3 / 车系兴趣 Top10 / 预算偏好 / 首付区间 / 能源偏好 / 标签总数 / 最近更新时间
  - 画像详情抽屉：身份与环境、8 类标签全量（含来源 / 频次 / 首末时间）、写入时间线回放、设备-账号绑定链路、人工修正入口
  - 导出：CSV / JSON、字段可勾选、手机号默认脱敏、留痕、大任务异步
- **标签字典**
  - 8 类标签的取值口径 / 写入来源 / 触发规则 / 排序与上限
  - **⟳ 更新字典**：上传需求文档（.md/.txt/.docx/.pdf）**或粘贴飞书文档链接** → AI 识别新规则与写入规则 → 变更预览（可逐条采纳）→ 更新至字典并留痕
- **标签分布看板**：预算段 / 首付区间 / 月供区间 / 能源类型 / 品牌 Top10 / 画像完整度

## 说明

- 纯静态单文件（`index.html`），无构建、无依赖，双击即可打开
- 数据均为模拟数据，不含真实用户信息
- 需求文档见 [PRD.md](PRD.md)
- 设计语言：品牌黄 `#FFE100` + 黑 / 白 + 圆角胶囊标签（Web 风格）
